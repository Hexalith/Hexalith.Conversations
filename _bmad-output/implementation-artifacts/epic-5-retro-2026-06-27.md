## 7. Key Lessons

1. **Final evidence needs self-checking guards.** Source hashes, manifest containment, changed-file boundaries, and vocabulary checks should be generated and validated together.
2. **Ready for signature is not signed.** The final artifact is useful precisely because pending decisions remain pending.
3. **Residual coupling can be acceptable when it is explicit.** Removing `Conformance.Tests -> Server` would weaken evidence today, so the honest outcome is retained coupling with a follow-up path.
4. **Directional metrics are not target approval.** SM-1 and SM-2 look strong, but OQ-2 still controls whether the target is officially accepted.
5. **Environment limitations need a canonical mitigation.** The xUnit executable fallback is now documented and repeatedly proven.
