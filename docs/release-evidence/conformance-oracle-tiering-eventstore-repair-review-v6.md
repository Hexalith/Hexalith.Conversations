## Guard correction

The first authenticated namespace cut has an exclusive `ValidUntil` boundary. The reader previously compared the final cut's revision and source heads but could return values after the first cut expired during folding if the issuer renewed that same revision. `SourceNamespaceSnapshotReader` now checks the initial cut's validity immediately before releasing values. A new `ExpiredInitialCutReturnsNoValues` regression advances a manual clock during the fold and supplies a renewed final cut with the same revision and heads. The focused reader suite passes 22/22 with no failed, skipped, or not-run cases; its Debug test project build has zero warnings and errors. The v6 packet binds the exact changed reader and test bytes, and the unchanged result/status source bytes.
